## 0. 一句話結論

V3 外殼樣「比競品更容易往前傾倒」的根因，**不是底座不夠長，而是合成重心（CG）偏高、偏前，且後方欠缺有效配重力臂**。
建議以 **A 底座後-底部配重 ＋ B 降重心／內部配置後移 ＋ C 金屬底板** 為主軸三管齊下；
並優先確認一件事：**這次送測的 V3「外殼樣」是否已裝到量產等重的內部配重／PCB**——若為空殼，前傾會被明顯放大，須先以量產等重樣重測再定案。`【需查證】`

## 2. 根因分析（工程觀點）

### 2.1 傾倒是「靜態穩定 / 力矩平衡」問題

把「充電座＋磁吸手機」視為一個剛體，繞**底座前緣支點（前腳接觸線）**旋轉。是否傾倒取決於兩個力矩誰大：

- **抗傾力矩（穩定）** ≈ `W_總 × d`
  - `W_總`＝整機＋手機的總重量
  - `d`＝**合成重心 CG 到前支點的水平距離**（CG 越靠後，d 越大越穩）
- **傾倒力矩（不穩定）** ≈ `手機重量前偏分量 × 前偏臂` ＋ `手施力 F × 施力高度 h`

**臨界條件**：當傾倒力矩 ≥ 抗傾力矩即開始翻倒。要更穩，就要「**加大 W_總 × d**」或「**降低施力力矩**」。

### 2.2 為什麼「底座較長」卻反而更容易倒？

長度加在哪裡決定有沒有用：

- 若加長主要在**前方**（把前支點往前推），對抗傾幫助有限，反而讓充電頭／手機更懸空前偏 → **CG 前移**、d 變小。
- 真正增穩的是：**後方要有重量**（把 CG 往後拉、加大 d 的力臂）＋ **整體重心要低**（降低 F×h 的敏感度）。
- 推論：競品很可能是「**底座短但底部重、重心低**」；PQI 是「**底座長但偏輕、重心偏高偏前**」——長度優勢被重量分布抵銷。`【假設】`（待 2.4 量測驗證）

### 2.3 幾何放大因素

- 充電頭在傾角下往前**懸伸（cantilever）**，手機貼在頭的前面 → 手機 CG 落在前支點**前方或正上方**，本就接近臨界。
- 施力方向（照片藍箭頭）作用在**手機上緣、離支點高**→ 力臂 h 大，小力就能產生大傾倒力矩。

### 2.4 V3 外殼樣特有風險（第一優先確認）

「外殼樣」常只有外觀件，**未必裝上量產的 PCB／變壓／磁鐵／配重**。若為近似空殼：

- 底座幾乎沒重量 → `W_總` 與 `d` 都被「頭＋手機」主導 → **前傾被嚴重放大**，未必反映量產真實表現。
- **行動一**：向協力廠確認送測樣的**實際重量與重量分布**，並以**量產等重樣**（或加等重配重）重做傾倒測試。`【需查證】`

## 3. 分級改善對策

> 每項標示：做法 / 預期效果 / 估算方向 / DFM·成本·模具影響 / 負責成員 / 信心度。
> 實際克數、位置、傾角均需協力廠量測 CG 後定案，故標 `【需查證】`。

### A｜底座後-底部配重（客戶建議，**首選**）

- **做法**：於底座**最後方、最底部**置入鋼板或鋅合金配重塊（鋼 ρ≈7.85、鋅合金 ρ≈6.6–7.1 g/cm³）。位置越後、越低，每克貢獻的抗傾力矩越大，同時降低重心。
- **預期效果**：同時加大 `W_總` 與 `d`，並降低 CG → 直接提升臨界傾倒力。
- **估算方向（力矩平衡示意）**：所需配重 `m ≈ (需補足的傾倒力矩) ÷ (g × 配重到前支點的水平臂)`。臂越長，所需克數越少。實際值待 CG 量測，初估量級 `【假設】` 數十克級（非最終值）。
- **DFM/成本/模具**：配重塊多為外購沖壓／壓鑄件＋卡扣或螺絲固定，**通常不需大改外觀模**；增加料重與組裝工序，成本可控。
- **負責**：吳定安（結構/固定/公差）、陳柏文（配重件 DFM/成本）
- **信心度**：高（方向正確，數值待量測）

### B｜降重心 / 內部配置後移

- **做法**：量產時把**最重的元件（PCB、變壓／電感、磁鐵環的金屬件等）配置在底座後-底部**；充電頭內部盡量輕量化（只留線圈＋磁環必要件）。
- **預期效果**：把系統 CG 往後、往下移，與 A 疊加，且**不額外增加太多料重**。
- **DFM/成本/模具**：屬 layout 與堆疊設計，越早期做越省；影響 PCB 走線與散熱佈局，需與電子團隊協調。
- **負責**：吳定安 × electronics-team（楊子晴 無線/線圈、內部配置）
- **信心度**：中高

### C｜金屬底板（壓鑄鋅／鋼板）

- **做法**：底座底面改用金屬底板（壓鑄鋅或鋼板）取代純塑膠底蓋。
- **預期效果**：**一舉數得**——兼具配重（降低且後移 CG）、止滑、質感提升、散熱面積。
- **DFM/成本/模具**：需新增金屬件與結合設計（膠合／螺絲／嵌件），料成本與組裝上升；CMF 需搭配表面處理。
- **負責**：陳柏文（壓鑄/DFM）、曾心怡（CMF 表面處理/一致性）、張逸晟（散熱效益）
- **信心度**：中高（效果好但成本較高，建議與 A 擇一或並用）

### D｜幾何：支點/鉸鏈後移、前腳前伸、四角腳墊平貼

- **做法**：在 ID 允許範圍內①將充電頭鉸鏈軸／頭部往**後移**，②前腳（或前緣止滑條）適度**前伸**加大前後腳距，③確保**四角腳墊平貼**無翹動（避免只有兩點接觸縮小支撐面）。
- **預期效果**：讓手機合成 CG 落在前支點**後方**、擴大支撐底面（base of support）。
- **DFM/成本/模具**：涉及外觀與結構件，**可能需改模**，屬中長期優化；短期先用 A/B/C。
- **負責**：吳定安、簡翔宇（ID 造型/人因）
- **信心度**：中（需與外觀設計平衡）

### E｜傾角可調（次要／選配）

- **做法**：提供更直立的可調傾角段位。
- **預期效果**：更直立時手機 CG 拉回底座上方 → 傾倒力矩下降。
- **取捨**：與「觀看角度」體驗、以及客戶「同傾角比較」的訴求有 trade-off；**列為選配**，不作為主解。
- **負責**：簡翔宇、吳定安
- **信心度**：中（有效但改變產品定位）

### F｜高摩擦止滑腳墊（輔助）

- **做法**：底部改用高摩擦 TPU／矽膠腳墊或止滑環。
- **預期效果**：**主要防「滑動」，不直接解「傾倒」**；僅在傾倒由前滑觸發時略有幫助。誠實定位為輔助措施。
- **負責**：曾心怡、吳定安
- **信心度**：低（就傾倒而言）；對整體穩定/質感仍值得做

### 對策優先順序建議

1. **先確認送測樣是否量產等重**（2.4，零成本、最關鍵）。
2. **主軸：A（配重）＋ B（降重心/後移）**，必要時加 **C（金屬底板）**。
3. **中長期：D（幾何）**；**選配：E**；**輔助：F**。

## 4. 驗證與測試方法

### 4.1 定義「臨界傾倒力」測試（可重複、可對競品比對）

- **固定變數**：同一支手機、同一磁吸頭、**同一傾角**、同一施力點與方向（比照客戶：手機上緣、朝前）。
- **量測**：以**推拉力計（push-pull gauge）**在定點緩慢加載，記錄**開始翻倒的臨界力 F_tip（單位 N）**。
- **對比**：PQI（改前 / 改後）vs 各競品，至少各測 3 次取平均。
- **延伸**：涵蓋輕手機與重手機、有／無保護殼。`【需查證】` 測試手機型號與重量。

### 4.2 重心量測

- 以**天平法**（或請協力廠由 CAD 導出）量測整機＋手機的**合成 CG 位置（X 前後 / Y 左右 / Z 高度）**與總重，做改前／改後對比，驗證 CG 是否確實後移、降低。

### 4.3 驗收目標

- **PQI 改後 F_tip ≥ 最佳競品**（含輕/重手機、有/無殼皆通過），並保留安全裕度。
- 確認測試樣＝**量產 BOM 等重**（回應 2.4 外殼樣風險）。

## 5. 給協力廠的溝通要點（可直接轉發）

1. **請確認送測 V3 外殼樣的實際重量與重量分布**；此樣是否已裝量產配重／PCB？若無，請提供量產等重樣或等重配重後重測。
2. 請提供**現況合成 CG（X/Y/Z）與總重**（實測或 CAD）。
3. 針對 **A 底座後-底部配重**：評估可行的**材料（鋼/鋅合金）、質量、擺放位置、固定方式、成本、對模具/組裝的影響與時程**。
4. 針對 **C 金屬底板**：評估壓鑄鋅/鋼板方案的**成本、結合工藝、CMF、散熱效益**。
5. 針對 **B 降重心/內部配置後移**：確認 PCB／重元件可否配置於底座後-底部，及其對走線/散熱的影響。
6. 請以 **4.1 臨界傾倒力測試** 提供**改前/改後與競品對比數據**，以及 **CG 位移量**。
