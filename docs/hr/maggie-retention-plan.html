Maggie 慰留面談暨工作重新分配完整方案

版本 v2.0(優化版)|日期:2026-08-05|狀態:待執行
30 秒摘要
Maggie 提出離職,原因不是待遇或人際,而是長期一人承擔多職、分工失衡、看不到改變的可能。
本方案核心策略:不靠情感慰留,靠「已經開始的具體改變」慰留。

三個交付重點:
1. 重新分工方案(不增加人力)— Maggie 從「什麼都做」收斂為「後勤行政暨營運支援」核心角色
2. 90 分鐘結構化面談流程 — Aaron 與 Frankie 分工明確,含逐字講稿
3. 落地時程與 Plan B — 留任後檢核機制;若仍離職,完整交接方案

一、背景與問題分析

1.1 離職信重點解讀

她寫的背後的訊息
「從採購開始,慢慢接下了倉儲、人事、會計、客戶對接、內部管理」職務範圍無邊界,累積式加載,從未卸載
「真正能分擔的人卻沒有增加」問題不是她的能力,是組織資源配置
「不是不累,而是選擇不說」過去沒有安全的回饋管道,或回饋後沒有改變
「直到最近,又有新的工作需要我承接時」有明確的壓垮點——最近一次新增工作是導火線,面談中必須問清楚是哪一項
「害怕因為自己的疲憊而影響工作品質」高責任感人格,擔心的是辜負信任,不是逃避工作
「希望未來接手這個職位的人,能夠擁有更合理的工作安排」離職信同時是一封組織診斷書——她已替公司指出問題
判讀結論:這是一封「還願意對話」的離職信。她花大量篇幅解釋原因、承諾交接、祝福公司,代表關係未破裂。慰留有機會,但只有一次機會——若面談只有口頭承諾而無具體方案,將加速她離開並帶走信任。

1.2 根本原因

  • 分工失衡:能者多勞變成能者「過」勞,新任務預設丟給最可靠的人
  • 單點依賴:採購、對帳、人事、客服、出貨全部集中一人,無備援
  • 回饋失靈:她「選擇不說」,表示說了沒用或不敢說——這是制度問題,不是個性問題

1.3 若 Maggie 離開,公司的風險盤點

風險領域影響嚴重度
採購執行發單、追交期、驗收中斷,供應商關係僅她掌握高
應收應付對帳帳務接手需長時間交接,錯帳風險高
人事行政勞健保、出勤等法定作業無人熟悉高

這張表不是拿來面談用的,是提醒 Aaron 與 Frankie:無論她留不留,「單點依賴」都必須解除。本方案的分工調整,同時就是風險解除方案。

二、面談目的與原則

目的

  1. 了解 Maggie 真正的離職原因(含導火線事件)
  2. 承認公司分工失衡的問題——不辯解、不淡化
  3. 提出已經決定執行的具體改善方案,而非「妳留下來我們再改」
  4. 與 Maggie 共同修訂新的工作內容
  5. 爭取留下核心人才;若留不住,守住信任、確保交接品質

4.4 新工作進件規則(防止問題復發的制度)

  1. 不預設由 Maggie 承接
  2. 先由 Aaron + Frankie 討論:負責人是誰?需要什麼資源?排擠了什麼既有工作?
  3. 指派後於週會公告,讓分工透明
  4. 任何人覺得負荷過重,可在週會直接提出——提出不需要理由,調整才需要理由
這一條是回應她信中「不是沒有壓力,而是告訴自己再撐一下」——要讓「說出來」變成制度預設,而不是個人勇氣。

六、面談流程(約 90 分鐘,六階段)

場地:安靜的獨立空間,勿在開放辦公區。時間:避開出貨與對帳高峰日。

階段 110 分鐘
Aaron
開場定調
AARON 講稿 Maggie,謝謝妳願意把心裡真正的想法寫出來。我和 Frankie 看了很多次,也討論了很多次。
今天找妳,不是希望妳立刻收回離職,而是希望我們一起討論,公司的工作方式是否有機會重新調整。
妳信裡提到的內容,我們沒有打算否認,也沒有打算解釋。我們承認,公司確實讓妳承擔了超過一個人應該承擔的工作。
階段 220 分鐘
Maggie 發言
只聽、只記錄。不打斷、不辯解、不急著給答案。

引導提問(視情況使用,不逐題轟炸):

  • 最近讓妳決定寫這封信的那件事,是哪一項工作?(找出導火線)
  • 現在手上的工作,哪一項最消耗妳?
  • 如果可以立刻移除一項工作,妳會選哪一項?
  • 有沒有哪些工作,其實妳做起來有成就感、願意保留?
  • 除了工作量之外,還有其他原因嗎?(待遇、氛圍、發展、家庭——開放但不逼問)
階段 315 分鐘
Frankie
回應與承認
FRANKIE 講稿 我最大的感受是,公司讓一個願意承擔的人,慢慢變成了承擔所有事情的人。
這不是妳能力不足,而是公司的分工出了問題。
所以今天不是請妳再撐,而是我們把組織重新調整——而且不管妳最後怎麼決定,這個調整都會做,因為它本來就該做。

最後一句是關鍵:表明改革不是慰留的交換條件,而是公司真心認錯。這會大幅提高可信度。

階段 420 分鐘
Aaron
說明新分工(拿出 4.1 分工調整總表逐項說明)
  • 客服第一線 → 小民|日常出貨 → Abby|採購決策 → Aaron
  • 人事制度、營運協調 → Frankie|行政支援 → Una
  • Maggie → 後勤行政核心(採購執行、對帳、人事行政、客訴二線)

  1. 承接人都已初步溝通過,不是紙上談兵
  2. 未來新增工作不會直接交給妳——說明新工作進件規則(4.4)
階段 515 分鐘
Frankie
確認需求
  • 這樣的分工,妳覺得合理嗎?哪裡需要調?
  • 有沒有我們遺漏的、妳其實還在做的工作?(隱性工作往往最多,務必問)
  • 除了分工,妳還需要什麼支持,才會願意留下來?
階段 610 分鐘
Aaron
總結
AARON 講稿 我們今天不是要求妳立刻決定,而是希望妳看到:公司願意改變,而且已經開始改變。
妳可以花幾天時間思考——我們約好 (具體日期,建議 3–5 天後) 再談一次,把所有問題談清楚。
不管妳的決定是什麼,這段時間妳為公司做的一切,我們都記在心裡。
⚠️ 務必當場約定回覆日期,不要說「妳想好再跟我說」——開放式等待讓雙方煎熬,也顯得公司不夠重視。

七、慰留配套(視面談狀況啟用)

分工調整是主菜;以下為備援選項,依階段 5 她說出的需求決定是否啟用,不要一次全給:

選項適用情境注意
職稱正名(如:行政管理主任)她在意的是被看見、被認可職稱需對應實質定位,勿淪為空銜
薪酬檢視她或市場行情顯示現職被低估信中未提待遇,勿主動用錢開場;但分工收斂後責任更聚焦,合理檢視是誠意
補休/彈性長期透支需要修復期給明確天數,勿說「妳自己安排」
教育訓練/發展路徑她想要長期職涯感對應新角色定位規劃

八、若 Maggie 同意留下:落地時程與檢核

第一週(立即執行)

  • 客服第一線 → 小民(Maggie 交付 FAQ 與範本)
  • 日常出貨 → Abby(Maggie 帶跑一輪)
  • 行政支援 → Una(建立交辦清單)
  • 全員公告新分工(以「組織優化」名義,不提離職事件)

第一個月(每週一次 30 分鐘檢核會)

參與人:Aaron + Frankie + Maggie,檢視三件事:

  1. Maggie 的工作量是否實際下降?(不是帳面移轉、實際還在做)
  2. 是否有工作回流?(承接人做不來又流回她手上——最常見的失敗模式)
  3. 流程是否需要調整?
🚨 回流是慰留失敗的頭號殺手。若發現回流,當週處理,由 Frankie 補訓練或調整 SOP,絕不允許「先請 Maggie 幫忙一下」。

三個月

  • 確認新組織穩定,Maggie 主觀負荷回到可長期運作水準(直接問她,1–10 分自評)
  • 評估是否需再優化或增補人力
  • 關鍵流程文件化完成(採購、對帳、人事行政 SOP)——同步解除單點依賴
  • 若有啟用薪酬/職稱配套,於此時兌現或確認進度

九、Plan B:若 Maggie 仍決定離開

慰留失敗不等於任務失敗——守住信任與交接品質,同樣是這場面談的成果。

  1. 尊重且感謝:不施壓、不冷處理。她信中已承諾「做好每一項交接」,這是最好的合作基礎
  2. 交接期規劃(建議與她協商 4 週以上):
    • 第 1 週:職務清單盤點(含隱性工作),排定交接優先序
    • 第 2–3 週:採購執行、對帳、人事行政流程文件化 + 帶承接人實作
    • 第 4 週:承接人獨立作業,Maggie 只答疑
  3. 交接文件最低要求:供應商聯絡清單與眉角、對帳流程與科目、勞健保作業行事曆、客訴處理案例集
  4. 好聚好散:離職面談正式致謝;保留回聘大門(「未來公司調整好了,隨時歡迎回來」)
  5. 對內溝通:公告聚焦感謝與交接安排,禁止任何咎責或八卦氛圍

十、成功關鍵訊息

核心不是:
「妳很重要,請留下來。」

而是:
「我們承認過去分工有問題,也已經開始調整。
未來希望妳留下來,但不是繼續硬撐,而是在分工清楚、有支援、可長期工作的環境中,一起把公司做好。」

三個支撐這句話的行動證據:

  1. 分工表在面談前已完成,承接人已溝通 → 「已經開始」不是話術
  2. 改革不以她留下為前提 → 誠意不是交換
  3. 新工作進件規則 → 問題不會在三個月後重演
