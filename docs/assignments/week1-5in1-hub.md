## 本週功課的做法:三個協作回合

本週評的**不是兩份漂亮的個人作業,而是你們的協作過程**。
功課依下面三個回合進行,回合之間的「檢核點」與「交叉評註」都是要繳交的產出 ——
跳過協作步驟直接各寫各的,做得再漂亮協作分也是零。

---

### 回合一|共同開局:單品速寫表(雙方同席,30 分鐘)

拿到新品的第一件事不是打開 Photoshop 也不是寫文案,是**兩人坐下來**回答這四格。
**限一頁、限 30 分鐘**,寫不完代表還沒想清楚,不是格子太小:

| 欄位 | 你們的答案 |
|------|------------|
| 目標客群(一句話,要具體到「誰、在什麼場景」) | 例:「用 MacBook 的遠距工作者,在咖啡廳只想帶一條線出門」→ 寫你們自己的 |
| 3 個競品與其價格帶 | ①(大牌)____ NT$____ ②(台牌)____ NT$____ ③(白牌)____ NT$____ |
| 我們的 1 個主打差異 | (只准寫一個,寫兩個以上退回) |
| 最怕消費者問的 1 個問題 | 例:「跟 NT$399 的白牌差在哪?」 |

> 競品構成是指定的:**1 個國際大牌**(Anker 或 UGREEN 同埠位款)、
> **1 個台灣中價位牌**(j5create、Innergie、Esense 等)、
> **1 個蝦皮白牌爆款**(該分類月銷前 10)。速寫表定案的 3 個競品,
> 回合二雙方就用同一組 —— 營運查數據、美工拆視覺,對象一致才接得起來。

---

### 回合二|雙軌同步作業 + 互講檢核(同一時段進行,約 2.5 小時)

**規則:同一時段、同席(或線上同步)作業** —— 營運做比較表、美工做拆解卡,
但過程中互為對方的資料來源:美工拆「賣點呈現」時直接問營運「這個賣點是真的嗎?」;
營運填「前 3 賣點」欄時,用美工抓下來的賣場截圖,不要各查各的。

**營運:競品比較表**(`competitor-comparison` 打底,再自行上平台查證):

| 欄位 | 競品 A(大牌) | 競品 B(台牌) | 競品 C(白牌) | LYCANDER 5in1 Hub |
|------|----------------|----------------|----------------|--------------------|
| 售價 | | | | (未定,填目標帶) |
| 埠位配置 | | | | 依第 0 節 |
| PD 瓦數 | | | | 100W |
| 評價數 / 星等 | | | | — |
| 月銷(估) | | | | — |
| 前 3 賣點(賣場自稱) | | | | 本週先空白 |
| 保固 | | | | 18 個月 |

**美工:競品視覺拆解卡 ×3**(對同 3 個競品的主圖 + 賣場前 3 張圖):

| 拆解項目 | 要寫什麼 |
|----------|----------|
| 配色 | 主色 / 輔色,給色票或截圖 |
| 字量 | 主圖上有幾個字?資訊圖一張塞幾個賣點? |
| 賣點呈現方式 | 用圖示?用數據?用情境照?用對比表? |
| 情境圖風格 | 棚拍 / 生活感 / 3D 渲染 / 素材庫感 |
| 一句話總結 | 「它想讓你覺得____」 |

**互講檢核點(15 分鐘,兩份文件各留一欄「對方觀點」)**:
雙軌做完先不要收工 ——
營運用 3 分鐘講「我們能打的位置 / 打不過的位置」;
美工用 3 分鐘講「誰的視覺和價格帶最一致 / 我們該像誰、絕不能像誰」。
**各自把對方的結論寫進自己文件的「對方觀點」欄**(50 字內)。
講評時會抽問:「對方的結論改變了你什麼判斷?」答不出來就是白講。

### 回合三|交叉評註 + 定位共識(約 1.5–2 小時)

**交叉評註(各至少 3 條,署名,計入個人分)**:
互相在**對方的產出上**留評註 ——

- 營運在美工的拆解卡上評:「這個視覺主張,數據支不支持?」
  (例:「白牌主圖喊 100W,但評論區一堆說充不動 —— 我們如果視覺上也喊瓦數,要附實測」)
- 美工在營運的比較表上評:「這個賣點做成圖難不難?會不會跟誰撞?」
  (例:「『18 個月保固』做成主圖賣點很弱,建議放 A+ 頁信任區,主圖留給散熱」)

**定位共識表(一頁,雙方同席完成)** —— 本週評分權重最高的產出,
之後 7 週所有文案與視覺的憲法。**其中「主打差異」與「視覺要傳達的一個詞」
兩欄,必須各引用至少 1 條對方的交叉評註作為依據**(標註評註編號):

| 欄位 | 共識 |
|------|------|
| 我們的價格帶落點 | 貼大牌 / 卡中間 / 壓白牌(三選一 + 一句理由) |
| 主打差異(承速寫表,只准一個) | 依據評註 #__ |
| 支撐差異的 3 個證據 | 每個證據要可驗證(材質、規格、保固),不可寫「品質好」 |
| 視覺要傳達的一個詞 | 例:「安靜的專業」—— 依據評註 #__,之後美工產出都要對齊這個詞 |
| 我們絕不說的話 | 至少 2 條(例:沒有實測前不說「絕不過熱」;不打「全網最低價」) |
| 協作紀錄 | 共同作業時段(日期時間)、互講檢核完成 ✔、交叉評註 營運 __ 條 / 美工 __ 條 |

## 繳交清單(checklist)

- [ ] 單品速寫表(一頁,回合一)
- [ ] 競品比較表(含「對方觀點」欄 + 美工的交叉評註 ≥3 條)
- [ ] 競品視覺拆解卡 ×3(含「對方觀點」欄 + 營運的交叉評註 ≥3 條)
- [ ] 定位共識表(一頁,含評註引用編號與協作紀錄)
- [ ] AI 使用對照:若用了 `competitor-comparison` 等 skill,附「AI 初稿 vs. 我們修改後」對照與一句修改理由

## 本週評分(總分 100)—— 協作就是主科目

| 面向 | 配分 | 本週評量重點 |
|------|------|--------------|
| **協作過程** | **30** | 互講檢核的「對方觀點」欄有沒有真材實料;交叉評註是否具體可執行(「不錯」「可以再優化」這種不算);共識表的引用是否真的影響了結論 |
| 完成度 | 10 | 4 項產出交齊、競品構成符合指定 |
| 市場思維 | 15 | 競品選得準不準、「能打/打不過」的結論誠不誠實 |
| AI 驗證分數 | 10 | 講師以 `validation-panel`(`consumers-taiwan`)測定位共識表的主打差異,購買意願分 ×2 |
| 說得出為什麼 | 5 | 各「一句話/理由」欄位有邏輯,不是形容詞堆疊 |
| 個人分 | 30 | 個人產出品質 10 + **自己留的交叉評註品質 10** + 組內互評 5 + 講評參與 5 |

**及格 60;80 分以上的定位共識表進入公司正式定位文件的候選。**

## 常見死法(前車之鑑,講評時會點名)

1. **分頭做完最後一天拼裝** —— 協作紀錄一看就穿幫:沒有共同時段、
   「對方觀點」欄是收工後補的。協作分(30)直接見底,這週等於白做。
2. **交叉評註寫成客套話** —— 「畫得很好」「分析很讚」不是評註。
   評註的格式是「你的 __ 和我看到的 __ 有出入/可以怎麼用」。
3. **競品全選白牌** —— 比誰都便宜當然好寫,但學不到定位。指定構成就是防這個。
4. **主打差異寫了三個** —— 「質感好、不過熱、又便宜」= 沒有定位。只准一個。
5. **數字沒有出處** —— 規格寫錯、瓦數抄競品。全部數字回溯第 0 節,抄錯一個扣完成度。
6. **AI 初稿直接交** —— `competitor-comparison` 的產出是草稿,月銷和評價數要自己查證。
   評的是你們的判斷與對話,不是 AI 的打字。
