## 流程總覽(缺一環就斷,依序進行)

```
步驟一(共同):單品速寫表 30 分鐘
   ↓
步驟二(營運):賣點企劃一頁 + 設計需求單(brief)
   ↓  ←—— 美工提問單(brief 不清楚就要問,問了要回)
步驟三(美工):依 brief 產出 1 張賣點主視覺 + 1 張草稿
   ↓
步驟四(共同):驗收對照表 + AI 消費者驗證
```

---

## 步驟一|共同開局:單品速寫表(雙方同席,30 分鐘)

企劃不能憑空發想,先兩人一起把地基打好。**限一頁、限 30 分鐘**:

| 欄位 | 你們的答案 |
|------|------------|
| 目標客群(一句話,具體到「誰、在什麼場景」) | 例:「用 MacBook 的遠距工作者,在咖啡廳只想帶一條線出門」→ 寫你們自己的 |
| 3 個競品與其價格帶 | ①(大牌 Anker/UGREEN)____ NT$____ ②(台牌)____ NT$____ ③(蝦皮白牌爆款)____ NT$____ |
| 我們的 1 個主打差異 | (只准寫一個,寫兩個以上退回) |
| 最怕消費者問的 1 個問題 | 例:「跟 NT$399 的白牌差在哪?」 |

---

## 步驟二|營運任務:發想企劃 + 寫設計需求單(約 2 小時)

### 2a. 賣點企劃(一頁)

用 `competitor-comparison` 查競品打底(月銷、評價數自己上平台查證),寫出:

| 欄位 | 內容要求 |
|------|----------|
| 定位一句話 | 我們在「大牌—白牌」光譜上的落點與理由 |
| 主打賣點(承速寫表,只准一個) | 例:鋁合金散熱不斷訊 / 100W 直充一線搞定 |
| 支撐證據 ×3 | 每個都要可驗證(規格、材質、保固),不可寫「品質好」 |
| 目標情緒 | 消費者看到圖的 3 秒內要產生什麼感覺(一個詞) |
| 競品視覺參考 | 附 2 張競品截圖:1 張「我們要學的」、1 張「我們絕不能像的」,各一句理由 |
| 禁用說法 | 至少 2 條(沒有實測不說「絕不過熱」;不打「全網最低價」) |

### 2b. 設計需求單(brief)—— 本週營運的主要評分產出

**寫給美工動手用的**,每一欄都要具體到「美工不用再猜」:

| 欄位 | 內容要求 |
|------|----------|
| 圖的用途與版位 | 例:蝦皮賣場第 2 張賣點圖(第 1 張是白底主圖) |
| 尺寸/格式 | 例:1000×1000px、JPG、檔案 <2MB |
| 必含元素 | 產品圖、賣點主標(給出文案初稿 ≤12 字)、副標(≤20 字)、規格數字(標明出自第 0 節哪一格) |
| 視覺重點順序 | 消費者視線第 1 眼 → 第 2 眼 → 第 3 眼各看到什麼 |
| 情緒與風格 | 承 2a 的目標情緒 + 參考截圖 |
| 不要什麼 | 至少 3 條具體禁令(例:不要爆炸貼紙感、不要超過 2 種字體、不要用紅色) |
| 交期 | 本週內雙方約定的時間 |

> **寫 brief 的紀律**:形容詞不算需求。「有質感」不合格;
> 「深色背景、金屬反光、留白 ≥40%、字型不超過 2 種」才是美工能執行的語言。

---

## 步驟三|美工任務:依 brief 產圖(約 2 小時)

### 3a. 提問單(產圖前,至少 2 個問題)

**拿到 brief 不准直接開工**,先回給營運至少 2 個問題,營運須書面回覆
(這份問答要繳交,是協作分的依據):

> 問題格式:「brief 說要____,但沒說____,我先假設____,對嗎?」
> 例:「主標說『不斷訊』,但沒給依據,圖上能不能放『4K@60Hz 穩定輸出』?這數字出自規格表哪格?」

### 3b. 產出(用 `visual-team` skill 輔助發想構圖,成品自己動手)

1. **草稿 ×1**:構圖框線稿或低精度排版,先給營運看過方向再細做
2. **賣點主視覺成品 ×1**:完全依 brief 規格交付
3. **設計說明(100 字內)**:我如何解讀 brief 的「目標情緒」、視線順序怎麼安排

> 美工的本事不只是圖漂亮,是**在 brief 的框裡把圖做對** ——
> 自由發揮超出 brief 又沒回頭確認的,算執行失誤不算創意。

---

## 步驟四|共同驗收:對照表 + AI 驗證(雙方同席,約 1 小時)

### 4a. 驗收對照表(逐項打勾,不合格項要寫處置)

| brief 條款 | 成品是否符合 | 不符合的處置(改圖 / 改 brief / 放行並記錄理由) |
|------------|--------------|--------------------------------------------------|
| 必含元素逐項 | ✔ / ✘ | |
| 視覺重點順序 | ✔ / ✘ | |
| 規格數字與第 0 節一致 | ✔ / ✘ | |
| 禁用說法未出現 | ✔ / ✘ | |
| 「不要什麼」3 條 | ✔ / ✘ | |

### 4b. 復盤三問(各 50 字內,雙方各自回答)

1. 營運答:brief 哪一欄美工問了才發現沒寫清楚?下次怎麼寫?
2. 美工答:哪個地方我猜了而不是問了?猜對還是猜錯?
3. 共同答:如果重來一次,流程哪一步最該改?

### 4c. AI 消費者驗證

講師以 `validation-panel`(`consumers-taiwan`)對成品圖 + 主打賣點跑購買意願評分,
結果計入評分並於講評討論。

## 繳交清單(checklist)

- [ ] 單品速寫表(一頁)
- [ ] 賣點企劃一頁 + 設計需求單 brief(營運)
- [ ] 提問單與營運回覆(≥2 問 2 答)
- [ ] 草稿 ×1 + 賣點主視覺成品 ×1 + 設計說明(美工)
- [ ] 驗收對照表 + 復盤三問(共同)
- [ ] AI 使用對照:若用 skill 打底,附「AI 初稿 vs. 我們修改後」與一句修改理由

## 本週評分(總分 100)

| 面向 | 配分 | 評量重點 |
|------|------|----------|
| **brief 品質(營運)** | **25** | 美工拿到能不能直接動手:必含元素具體、視線順序明確、禁令可執行;形容詞堆疊直接扣分 |
| **成品符合度(美工)** | **25** | 圖是否「在 brief 的框裡做對」:對照表通過率、視線順序落地、規格數字無誤;圖的完成度與美感 |
| 協作過程(共同) | 20 | 提問單問得準不準、營運回覆是否解決問題、驗收表誠不誠實(全打 ✔ 但圖文明顯不符 = 造假,重扣) |
| AI 驗證分數 | 10 | `validation-panel` 購買意願分 ×2 |
| 個人分 | 20 | 個人產出品質 10 + 組內互評 5 + 講評參與 5 |

**及格 60;80 分以上的成品圖與 brief 進入正式上架素材與需求單範本的候選。**

## 常見死法(前車之鑑,講評時會點名)

1. **brief 全是形容詞** ——「大氣、有質感、吸睛」,美工只能通靈。
   當場退回重寫,退回一次扣 brief 品質 5 分。
2. **美工不問就開工** —— 猜錯方向重做兩小時,不如先問兩個問題。提問單空白 = 協作分減半。
3. **圖很美但脫離 brief** —— 自由發揮沒回頭確認,驗收表一堆 ✘。這是執行失誤,不是創意。
4. **驗收表橡皮圖章** —— 全打 ✔ 但主標 14 個字(brief 限 12)。驗收造假重扣協作分。
5. **數字沒有出處** —— 圖上的瓦數、規格必須回溯第 0 節,抄錯一個扣成品符合度。
6. **AI 初稿直接交** —— skill 產出是草稿;競品數據要查證,構圖要自己動手。
   評的是你們的判斷與交接,不是 AI 的打字。
