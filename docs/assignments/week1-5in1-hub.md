| 欄位 | 你們的答案 |

## 三、美工任務:競品視覺拆解(約 2 小時)

對同樣 3 個競品的**主圖 + 賣場前 3 張圖**,各做一張拆解卡:

| 拆解項目 | 要寫什麼 |
|----------|----------|
| 配色 | 主色 / 輔色,給色票或截圖 |
| 字量 | 主圖上有幾個字?資訊圖一張塞幾個賣點? |
| 賣點呈現方式 | 用圖示?用數據?用情境照?用對比表? |
| 情境圖風格 | 棚拍 / 生活感 / 3D 渲染 / 素材庫感 |
| 一句話總結 | 「它想讓你覺得____」(例:大牌想讓你覺得專業可靠;白牌想讓你覺得夠用就好) |

**加一個判斷(100 字內)**:三家之中,誰的視覺和它的價格帶「最一致」?
誰有落差?LYCANDER 如果走「質感 + 不過熱 + 在地保固」,視覺上該像誰、絕不能像誰?

## 四、共同交接產出:定位共識表(一頁,約 1 小時)

營運和美工**一起**完成 —— 這頁是本週評分權重最高的產出,
它就是之後 7 週所有文案與視覺的憲法:

| 欄位 | 共識 |
|------|------|
| 我們的價格帶落點 | 貼大牌 / 卡中間 / 壓白牌(三選一 + 一句理由) |
| 主打差異(承速寫表,只准一個) | |
| 支撐差異的 3 個證據 | 每個證據要可驗證(材質、規格、保固),不可寫「品質好」 |
| 視覺要傳達的一個詞 | 例:「安靜的專業」「桌面美學」——之後美工產出都要對齊這個詞 |
| 我們絕不說的話 | 至少 2 條(例:沒有實測前不說「絕不過熱」;不打「全網最低價」) |
| 分工標註 | 營運:____ 完成 §二;美工:____ 完成 §三;§一、§四共同完成 |

## 六、本週評分(總分 100)

| 面向 | 配分 | 本週評量重點 |
|------|------|--------------|
| 完成度 | 15 | 4 項產出交齊、競品構成符合指定(大牌 + 台牌 + 白牌) |
| 協作品質 | 20 | 定位共識表是否真的「共識」:美工的視覺判斷(§三)與營運的能打位置(§二)有沒有接起來,還是各寫各的 |
| 市場思維 | 15 | 競品選得準不準、「能打/打不過」的結論誠不誠實 |
| AI 驗證分數 | 10 | 講師以 `validation-panel`(`consumers-taiwan`)測定位共識表的主打差異,購買意願分 ×2 |
| 說得出為什麼 | 10 | 三個「一句話/理由」欄位是否有邏輯,不是形容詞堆疊 |
| 個人分 | 30 | 個人產出品質 15 + 組內互評 10 + 講評參與 5 |

**及格 60;80 分以上的定位共識表進入公司正式定位文件的候選。**

## 七、常見死法(前車之鑑,講評時會點名)

1. **競品全選白牌** —— 比誰都便宜當然好寫,但學不到定位。指定構成就是防這個。
2. **主打差異寫了三個** —— 「質感好、不過熱、又便宜」= 沒有定位。只准一個。
3. **營運美工各交各的** —— 比較表說要打質感,拆解卡結論說該學白牌,§四硬湊。
   協作分直接見底。
4. **數字沒有出處** —— 規格寫錯、瓦數抄競品。全部數字回溯第 0 節,抄錯一個扣完成度。
5. **AI 初稿直接交** —— `competitor-comparison` 的產出是草稿,月銷和評價數要自己上平台查證。
   評的是你的判斷,不是 AI 的打字。
