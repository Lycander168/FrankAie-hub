# 提案文件（Proposals）

存放對外提報用的簡報與提案文件。命名慣例：`YYYY-MM-主題.{html,md}`。

- HTML 為可直接展示的簡報（瀏覽器開啟、← → 翻頁、Ctrl+P 列印成 PDF）
- MD 為同內容編輯稿，價格等機密欄位以【提報前確認】標示，對外前由內部填入
