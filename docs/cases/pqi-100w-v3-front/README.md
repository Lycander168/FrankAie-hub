## 比例與單位

盒面實際尺寸 88 × 168 mm（含掛耳），稿件以 **2× 放大**繪製：
1 mm = 7.559 px（96 dpi 下的兩倍）。輸出實體檔時整體縮 50%。

## 素材狀態

- `cable-hero.jpg`、`plug-macro.jpg`、`pqi-logo.jpg` 由客戶提供的兩版比稿裁切而來，**為暫代素材**。
  正式稿需重拍：單一側逆光、冷白調、地面淺投影，鋁殼高光須保留。
- `v1-front.jpg`、`v2-front.jpg` 為原始兩版比稿正面，僅供縮圖驗證對照。
- 黑／藍 SKU 的線材照片需另拍，目前沿用白色線材示意。
