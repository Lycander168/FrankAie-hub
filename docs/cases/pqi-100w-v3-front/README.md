## 比例與單位

盒面實際尺寸 88 × 168 mm（含掛耳），稿件以 **2× 放大**繪製：
1 mm = 7.559 px（96 dpi 下的兩倍）。輸出實體檔時整體縮 50%。

## 素材狀態

- `cable-hero.jpg`、`plug-macro.jpg`、`pqi-logo.jpg` 由客戶提供的兩版比稿裁切而來，**為暫代素材**。
  正式稿需重拍：單一側逆光、冷白調、地面淺投影，鋁殼高光須保留。
- `v1-angle-hero.jpg` 為 B 版主視覺，裁自版本 1 的接頭角度。
- `v1-front.jpg`、`v2-front.jpg` 為原始兩版比稿正面，僅供縮圖驗證對照。
- 黑／藍 SKU 的線材照片需另拍，目前沿用白色線材示意。

## 待確認才可上稿

「10,000-BEND TESTED」第二徽章須待實測報告、測試方法與依據標準確認後才可付印，

## 字體

Archivo（標題與數字）＋ IBM Plex Sans（規格與小字）。
正式印刷檔請改用集團指定字體並確認授權範圍。

## A / B 兩版主視覺

同一套版型、徽章、圖標列、色點與底部鎖定，只有主視覺與圓形小圖對調：

- **A（`Front`）整條捲線** — 沿用版本 2 的攝影。長度與線材質地一次說完，縮圖與貨架測試最穩。**建議作為零售與電商主圖的主打版本。**
- **B（`FrontB`）接頭角度** — 版本 1 的構圖，改為滿版裁切。質感訴求最強，但看不到整條線，縮到 300 px 時主體偏抽象。**留給高單價陳列、廣告素材與 A+ content。**

兩版共用同一套刀模與版型，切換成本只有一張圖。
