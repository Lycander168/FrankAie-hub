## 零、產品基準資料(講師開課前確認)

以下規格為 USB-C 5-in-1 Hub 的典型配置假設,**開課前請以實際產品規格書修正**,
全班使用同一版本,避免各組基準不一:

| 欄位 | 假設值(請確認) |
|------|------------------|
| 埠位配置 | HDMI 4K@60Hz ×1、USB-A 3.0 ×2、USB-C PD 100W ×1、USB-C data ×1 |
| 材質 / 外觀 | 鋁合金外殼、編織線材、太空灰 |
| 尺寸重量 | 約 100 × 30 × 12 mm / 約 60 g |
| 相容性 | MacBook / iPad Pro / Windows 筆電 / Switch(如支援請標明) |
| 目標售價帶 | NT$ 890–1,490(待第 3 週定價作業產出後定案) |
| 主要銷售通路 | 蝦皮 / momo / 官網(外銷:Amazon US/JP) |
| 保固 | 18 個月(請確認) |

> 沒有規格書之前,各組**不得自行編造規格**放進 listing 或圖面 ——
> 這本身就是第一課:電商文案與美工的每一個數字都要有依據。

**這個品類的已知戰場**(講師可在第一週開場時給):
競爭對手是 Anker、UGREEN、Belkin、j5create 等大牌 + 白牌低價海;
消費者常見抱怨集中在:**過熱、HDMI 閃屏/斷訊、傳輸速度虛標、MacBook 相容性、PD 瓦數不實**。
LYCANDER 要贏,不能只比價格 —— 這是全期功課要回答的核心問題。

## 8 個技能套用在 5in1 Hub 上的完整題目

> 「每週一品」制下,課程當週只做其中一題(5in1 Hub 排第 1 週,做第 1 題);
> 期末深潛選了 5in1 Hub 的組,則把 8 題做齊。

### 第 1 週|市場與視覺定調:「我們憑什麼贏 Anker?」

- **營運**:做 3 個競品的比較表 —— 指定 1 個大牌(Anker 或 UGREEN 同埠位款)、
  1 個中價位台灣品牌、1 個蝦皮白牌爆款。欄位:售價、埠位、PD 瓦數、評價數、
  星等、月銷、前 3 賣點。用 `competitor-comparison` 打底。
- **美工**:拆解同 3 個競品的主圖與賣場視覺:配色、字量、賣點呈現方式、
  情境圖風格,各給一句「它想讓你覺得什麼」。
- **共同交接**:一頁「LYCANDER 5in1 Hub 定位共識表」——
  我們的價格帶落點、主打差異(例:鋁合金質感 + 不過熱 + 在地保固)、視覺要傳達的一個詞。

### 第 2 週|痛點 → 賣點圖:「把過熱焦慮變成購買理由」

- **營運**:用 `review-miner` 挖 3 個競品合計 50+ 則評論(蝦皮/momo/Amazon),
  整理前 5 大痛點與前 5 大讚點,每個痛點附 2 則原文摘錄。
  預期會撞到:過熱、HDMI 閃屏、速度虛標、接 MacBook 斷線。
- **美工**:挑前 3 大痛點,各做 1 張賣點圖草稿。
  例:過熱 → 鋁合金散熱示意(溫度對比);閃屏 → 4K@60Hz 穩定輸出;
  虛標 → 實測傳輸速度數據圖。
- **共同交接**:設計需求單(brief)——「痛點 → 證據(評論摘錄)→ 視覺訴求 → 禁用說法」
  對照表。**禁用說法**欄必填:沒有實測數據前,不得寫「絕不過熱」「最快」。

### 第 3 週|定價與質感路線:「NT$890 還是 NT$1,490?」

- **營運**:用 `pricing-calculator` 算 3 組定價(對標白牌 / 卡位中間 / 貼近大牌),
  每組含:通路抽成(蝦皮/momo 費率)、運費、廣告預算佔比、毛利率、損益兩平台數。
- **美工**:兩條視覺路線各做 1 張情境圖 ——
  A 路線「高 CP 值」(明亮、多埠位同框、價格感);
  B 路線「質感選物」(深色調、金屬質感特寫、桌面美學)。
- **共同交接**:一頁選擇說明 —— 選哪個價位 × 哪條視覺路線、為什麼互相匹配
  (例:選 NT$1,290 就不能用白牌式的視覺,理由要寫清楚)。

### 第 4 週|Listing × 主圖:「搜尋『usb c hub』時被看見、被點擊」

- **營運**:完整 listing —— 標題(含 `seo-keyword-expander` 展開的關鍵字:
  usb c hub、typec 轉接、macbook 擴充、hdmi 轉接…)、5 條 bullet、
  產品描述、後台關鍵字。用 `listing-optimizer` 檢查。
- **美工**:平台規範白底主圖 ×1(產品佔比 ≥ 85%、埠位清楚可數)+
  規格資訊圖 ×1(5 個埠位逐一標註規格,尺寸重量標示)。
- **共同交接**:一致性檢查表 —— 標題與 bullet 的每個賣點,在主圖/資訊圖上
  找得到對應視覺嗎?圖上的每個數字,listing 裡有依據嗎?逐項打勾。

### 第 5 週|廣告素材對:「一條 hook 配一張圖」

- **營運**:用 `ad-hook-writer` 寫 10 條不同角度的 hook,至少涵蓋:
  痛點型(「開會投影到一半黑屏?」)、場景型(「一個 hub,桌面只剩一條線」)、
  數據型(「100W 直充,螢幕鍵盤硬碟同時上」)、對比型(對 Anker 的價格/保固差異)。
  選 3 條並說明理由。
- **美工**:為選出的 3 條 hook 各做 1 組廣告圖(方形 1:1、橫幅、限動直式 9:16)。
- **共同交接**:配對說明 —— 哪句配哪張、投放版位(FB/IG/Google)、
  預期點擊動機是什麼。

### 第 6 週|A+ 描述頁:「從故事到下單」

- **營運**:把 listing 改寫成敘事文案(`copy-humanizer` 潤稿):
  遠距工作/行動辦公的場景切入 → 線材地獄痛點 → 5in1 解方逐埠說明 →
  材質與散熱 → 台灣保固與售後。
- **美工**:依敘事節奏設計 5 張商品描述長圖,首圖是情境、尾圖是保固信任背書。
- **共同交接**:分鏡稿 —— 每張圖對應哪段文案、想喚起什麼情緒、
  滑到第幾張應該產生「加入購物車」的衝動。

### 第 7 週|改版實戰:「診斷一個真實賣場」

- **營運**:拿 LYCANDER 現有賣場(或講師指定的一個表現不佳的同品類賣場),
  寫診斷報告:3 個問題(附截圖佐證)+ 3 個改善行動 + 預期指標變化
  (點擊率/轉換率)。用 `data-analyst` 視角。
- **美工**:依診斷報告重做 1 張該賣場的主圖或首張描述圖,附 before/after 對照。
- **共同交接**:改版提案一頁 —— 問題 → 改法 → 預期指標,過 `quality-gate` 對抗式審查。

### 第 8 週|再行銷組合:「把棄購的人撈回來」

- **營運**:用 `email-sequence-builder` 設計 3 封棄購挽回序列 ——
  1 小時後(提醒 + 免運)、24 小時後(痛點加深:明天開會還要搶轉接頭?)、
  72 小時後(限時折扣或加贈收納袋,擇一並算毛利影響)。
- **美工**:每封 email 主視覺 banner ×1;選修:主打賣點 10–15 秒動態
  (`animation-designer`,例:一條線接上,五個裝置亮起)。
- **共同交接**:三封完整 email 樣稿(文案 + 圖合體,可直接寄測)。

## 期末專題:LYCANDER 5in1 Hub 上架企劃書 + 視覺包

整合 8 週產出,每組繳交:

1. **上架企劃書**:定位、定價與損益、完整 listing、廣告計畫、email 序列
2. **視覺包**:主圖 ×1、附圖 ×6(情境 ×2、資訊 ×1、賣點 ×3)、描述長圖 ×5、廣告圖 ×3
3. **驗證報告**:`validation-panel` AI 消費者評分 ——
   內銷跑 `consumers-taiwan`,並加跑 `consumers-usa` 或 `consumers-japan`
   模擬 Amazon 外銷(兩個市場的回饋差異寫 3 點觀察)

**通過門檻**:台灣小組平均購買意願 ≥ 3.5/5。
最高分組的成果由主管複核後,**作為正式上架素材的候選版本**。

## 本產品功課的三個特別提醒

1. **數字紀律**:hub 品類的虛標(瓦數、速度)是消費者最大怒點,
   也是平台檢舉重災區。全期功課中,任何規格數字都必須回溯到第 0 節的基準表;
   rubric 的「協作品質」分會直接扣圖文數字不一致的組。
2. **相容性是隱形痛點**:MacBook / iPad / Switch 支援與否,
   營運要在 listing 講清楚,美工要在資訊圖上畫清楚 —— 這是退貨率的第一道防線,
   可請 `electronics-engineer` skill 協助確認技術說法是否正確。
3. **別掉進價格戰敘事**:如果某組 8 週下來的唯一賣點是「比 Anker 便宜」,
   講評時要點出來 —— 那是採購策略,不是品牌策略。
