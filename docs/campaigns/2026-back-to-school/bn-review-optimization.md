  2. 開學檔期卻**完全沒有「開學」字樣**。
  3. 五件產品散置、大小相近,無主推層級;放射光暈吃掉深色產品輪廓。
  4. 「挑戰最低價」宣稱風險(見二-B)。
  5. 「5TB SSD」標示矛盾(見二-A)。
  6. 無 CTA。
  7. 「藍芽」錯字(正:藍牙)。

  3. 山景與開學/3C 無關,無開學字樣。
  4. 底部小物件無名稱標示,成為雜訊。

### BN-3|紅底黃圓「開學用品 CP值爆棚」版

  4. 手寫字量過多,行動端縮圖可讀性下降。

## 二、跨張共通問題(依嚴重度)

- 🔴 **A. 「SSD」與「硬碟」標示矛盾——上線前必改**:四張皆標「5TB SSD $4,999」,但 BN-2 同時稱「廣穎軍規硬碟」,且產品外觀與容量價格帶(5TB/$4,999)為 HDD 行情。若實際出貨為 HDD 而標 SSD:公平交易法第 21 條廣告不實風險 + 必然的客訴退貨。→ **與產品部確認實際規格,全數統一**(定稿採「軍規防摔行動硬碟」)。
- 🔴 **B. 「最低價」系宣稱**:「挑戰(市場)最低價/最殺價/驚爆價」屬無法舉證的最高級價格宣稱,有裁罰前例風險。→ 改可自證表述:價格事實 + 現省金額。
- 🟠 **C. 檔期日期表現不一致**:BN-4 手寫「8/25-916」。→ 四張統一印刷體「8/25 – 9/6」。
- 🟠 **D. 四張像四個活動**:橘爆炸/黑山景/紅喜慶/綠黑板並行,無法累積活動認知。→ 統一為一套主視覺系統(以 BN-4 開學黑板綠現代化)。
- 🟡 **E. 全數無 CTA**。
- 🟡 **F. 細節**:「藍芽」錯字;第三方品牌配件命名方式;贈品限制揭露不全。
